About this demo and its limits

This demonstrates shared state and supervised room replacement on BEAM. It is not a speed or GIL isolation test. This is an anonymous local demo, not Discord authentication.

Leave stops delivery receipts, but you can still view the room. Closing a page disconnects updates without leaving. Changing rooms does not leave the previous room.

Each room allows 8 distinct identities and 100 events before restart. Departed identities still occupy slots. The latest 32 messages are retained. Messages allow 256 characters and 1024 UTF-8 bytes.

There are at most 32 streams and 16 admitted web operations. Subscription queues allow 4096 bytes. Slow writes disconnect after 5 seconds. There is no persistence or replay. A cancelled request can still have effects.

Only the stream updates messages after page load. Action replies cannot replace newer room state. Drafts stay local and are not cleared by acknowledgements.
