PyBeam control plane

This server runs on CPython with Starlette and Jinja, not on native BEAM. The distributed walkthrough remains unavailable until a prepared runtime is reviewed.

One job at a time, at most four queued/running and 16 retained per session. Benchmark comparisons always use the shared runner load lock. Logs show at most 16 KiB. Ordinary jobs have a 30-second guardian budget. The finite distributed walkthrough has a 120-second budget. Limits are sampled watchdog checks. Stop requests are not rollback. Side effects may remain uncertain.

Run all queues only the enabled scalar profiles, serially. Missing runtime assets disable native cards. Only this checkout's fixed commands are trusted. No other worktree heads are executed.
