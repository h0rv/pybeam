One job at a time, at most four queued/running and 16 retained per session. Benchmark comparisons always use the shared runner load lock. Logs show at most 16 KiB. Each running workload has a 30-second guardian budget. Limits are sampled watchdog checks. Stop requests are not rollback. Side effects may remain uncertain.

Run all queues only the enabled scalar profiles, serially. Missing runtime assets disable native cards. Only this checkout's fixed commands are trusted. No other worktree heads are executed.
