What happens

FastAPI increments a shared counter in BEAM ETS, then publishes a notification. Each connected tab receives fresh HTML after a new read from BEAM, not from the notification payload.

Watch the terminal for increments, publications, and subscription connections, updates, and disconnects.

This counter is shared by everyone on one BEAM node. It is node-local, not persistent. Restarting the node clears it. This public demo has no authentication or production authorization.
